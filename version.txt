1.0.4
- Fixed randomized NPC weapon reinforcement scaling so unique +5 weapons map correctly to normal +15 weapons and vice versa.
- Linked randomized weapon loadouts across NPC variants, matching armor variant behavior while keeping Kirk invasions unlinked for more variation.
- Documented NPC IDs in weapon category profiles for documentation when making changes.

1.0.3
- Expanded the NPC weapon randomization pools using a curated weapon and shield list.
- Added NPC specific weapon category profiles so each NPC can roll from curated weapon categories instead of a single global pool.
- Refactored NPC weapon category/profile logic out of chr_setup.py into dedicated NPC weapon modules.
- NPC melee weapon randomization now respects each NPC’s assigned weapon profile.
- NPC weapon candidates are filtered by the NPC’s STR/DEX/INT/FTH requirements before assignment.
- Greatbows are excluded from NPC weapon randomization because NPC bow users do not have great arrow ammo.

1.0.2
- Update version/changelog to 1.0.2
- Fixed PTDE `menu.msgbnd` parsing for archives with legacy encoded filenames.
- Randomized starting stats warning now only appears for Dark Souls: Remastered.
- Cleaned up the GUI layout and option hover behavior.

1.0.1
- Added `Randomize Starting Stats` option.
- Starting stats are randomized from 8 to 15 while preserving each class's vanilla stat total.
- Deprived is left unchanged.
- Added an online-ban warning when enabling randomized starting stats.

1.0.0
- Bumped version to 1.0.0.
- Added dark mode support to the GUI.
- Added `Randomize Starting Gifts` option.
- Added curated starting gift pools for non-ring gifts and ring gifts.
- Added randomized starting gift output to seed info.
- Added menu text updates so randomized gifts show correct names and descriptions in character creation.
- Reordered GUI options so `Randomize Starting Gifts` appears above `Fashion Souls`.
- Reordered option descriptions to match the GUI layout.
- Expanded the GUI description area to reduce hover text cutoff.
- Starting gift randomization now restores game/menu files from backups before each export, preventing old randomized gift data from leaking into later seeds.
- Curated gift names/descriptions to fit the Dark Souls character creation UI.
- Fixed dropdowns allowing typed/erased input by making them read-only.
- Fixed dropdown text remaining selected after choosing an option.
- Improved light theme combobox/dropdown border visibility.
- Fixed starting gifts not reverting to vanilla when the option was unchecked after a randomized gift run.
- Fixed menu backup handling that previously contained a no-op self-move.

0.8.1
- When searching for Dark Souls game files to randomize, stop searching the list after it is found.  This prioritizes the relative path, meaning if you put the randomizer EXE in the same folder as the Dark Souls folder you want to randomize it will not accidentally grab another folder on the machine if you have several Dark Souls installed.
